以下列出系统在每次检测中执行的全部判定规则。本页仅作参考，不可修改。

一 挂马检测（malware）
最高优先级
#规则触发条件
1新增外部域名脚本页面新增了非本站域名的 <script src="..."> 标签
2内联脚本变更页面中内联 <script>...</script> 的内容与基线不一致
3新增 iframe页面新增了任何 <iframe> 标签（无论是否有 src）
4敏感关键词页面文本中出现敏感关键词（赌博 / 色情 / hacked 等）
5外部 iframe页面包含指向外部域名的 iframe（即使基线就有也会标记 warning）
6可疑脚本路径脚本 src 包含 "eval" 或 "base64" 等可疑特征
二 篡改检测（tamper）
中优先级
#规则触发条件
7页面标题变更<title> 内容与基线不一致
8新增本站脚本页面新增了本站域名的 <script> 标签
9脚本移除基线中存在的 <script> 标签被移除
10iframe 移除基线中存在的 <iframe> 被移除
11文本内容变化页面可见文字长度变化超过 5%（日期、时间戳等动态文本已归一化）
12页面结构变化body DOM 骨架（标签 + id 序列）与基线不一致；style 数值、构建 hash、时间戳等动态值已归一化，天然抖动不触发
13截图像素差异与基线截图对比，像素变化超过阈值（默认 5%）
三 可达性检测
#规则触发条件
14连续失败连续 3 次检测失败触发告警
四 优先级说明
  • 挂马（malware）优先级最高，即使同时有篡改特征也标记为挂马
  • 不可访问次之，HTTP 非 200 直接判定为不可访问
  • 篡改（tamper）仅在没有挂马和不可访问时才判定
  • 关键词检测同时对比内置关键词（系统内置，不可删除）和自定义关键词（在设置页可自行添加 / 删除）
  • DOM 对比和截图对比并行执行，结果合并判定，互不影响
  • 对比前自动归一化动态值（时间戳、日期文本、style 属性数值、资源文件名构建 hash、URL 随机参数 → 占位符），天然抖动不引起误报
  • 每个页面可配置忽略区域（CSS 选择器），对比前剔除地图、轮播、计数器等天然动态区块，在"客户与站点 → 编辑页面"中设置
